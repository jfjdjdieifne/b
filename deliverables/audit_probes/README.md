# مجسات التدقيق المستقلة لـ Stage 4B-2 (دليل إعادة الإنتاج)

شُغّلت من جذر المشروع (`trading_project/`) بمسار الحزمة:

```bash
PYTHONPATH=src python3 <probe.py>
```

| الملف | ماذا يثبت | النتيجة |
|---|---|---|
| probe1_mirrors_independent.py | يبني المحركات الأربعة المغلقة مباشرة ويقارن مخرجاتها العامة الفعلية بالمرايا المحلية المجمّدة (أسماء+ترتيب+عدد) | PASS (23/16، 26/20، 27/21، 30/17) |
| probe2_attacks.py | هجمات تبديل المجال المتماسكة، تبديل الجداول، حذف/تعديل حقائق قبل T، ثبات البادئة تحت الامتداد (موضعي وزمني)، رفض BAR_PRE_CLOSE/cross-timeline، هياكل مدمجة | كل الدفاعات صمدت |
| probe3_runtime_equiv.py | محرك شرير يضيف/يحذف/يعيد ترتيب أعمدة ⇒ البناء يرفض (إثبات أن الفحص الديناميكي للمرآة حقيقي لا شكلي) | PASS |
| probe4b.py | التغطية الصحيحة لأعمدة السوق المارّة: كل عمود يغيّر حقائق مشتقة مقارَن بالسوق المختوم؛ volume غير مستهلك أصلاً | PASS |
| probe5_semantics.py | علم نفس-الدفعة صادق ومستقر تحت الإسقاط؛ الكيانات traceable 1:1 لأحداث الإنشاء؛ DR يستخدم الجدول الأصلي | PASS |
| probe6b.py | حقن عمود غريب وسط bar_frame (ملاحظة NON-BLOCKING مسجَّلة)، رفض العمود المكرر في الأحداث، حصانة المدخلات بعد البناء | ملاحظة غير حاجبة |

(ملف probe4_passthrough.py نسخة مبكرة أعطت إنذارات كاذبة لأنها قارنت كامل البار بما فيه
أعمدة الإدخال المنعكسة؛ الصحيح هو probe4b.py الذي يقارن الحقائق المشتقة فقط.)

كل المجسات قراءة فقط ولا تكتب داخل شجرة المشروع.
