# دليل التشغيل المحلي — README_LOCAL

هذا المجلد يتيح لك فحص ملف بيانات كبير على جهازك مباشرة، بدون نسخ الملف إلى
المشروع، وبدون المساس بأي ملف من ملفات المشروع المغلقة. ملفات المشروع داخل
مجلد `trading_project` محفوظة بت-مقابل-بت ولا يغيّرها أي أمر هنا.

---

## 1) تثبيت Python (مرة واحدة)

حمّل Python 3.10 أو أحدث من الموقع الرسمي: https://www.python.org/downloads/

أثناء التثبيت: فعّل الخيار **Add python.exe to PATH**.

## 2) فك ضغط ZIP

فك ضغط الحزمة في مسار بسيط، مثلاً: `C:\LocalWorkstation`
(المسار يحتوي مسافات؟ لا مشكلة — النظام يدعمها).

## 3) الإعداد (مرة واحدة فقط)

افتح PowerShell داخل المجلد الذي فككته (اضغط Shift + كليك يمين على المجلد
واختر Open PowerShell window here) ثم اكتب:

```
.\setup_windows.bat
```

انتظر حتى يظهر: تم الاعداد بنجاح (قد يستغرق دقائق).

## 4) فحص ملف البيانات

الخيار أ — تعطي المسار مباشرة (الملف يبقى على قرصك ولا يُنسخ):

```
.\inspect_data.bat "D:\MarketData\BTCUSDT-aggTrades-2026-05.csv"
```

الخيار ب — بدون مسار؛ سيطلب البرنامج منك لصق المسار:

```
.\inspect_data.bat
```

الخيار ج — اسحب ملف البيانات وأفلته فوق `inspect_data.bat` مباشرة.

انتظر رسالة: تم الفحص بنجاح (على الملفات الكبيرة قد يستغرق دقائق).

## 5) مكان التقرير

داخل المجلد `outputs` ستجد ملف JSON صغير اسمه يبدأ بـ `inspect_` ويحوي وقت
الإنشاء. أرسل هذا الملف كما هو — فيه بصمة الملف SHA256 وكل التفاصيل.

## 6) التحقق من سلامة المشروع

```
.\verify_manifest.bat
```

يجب أن تظهر النتيجة: جميع الملفات مطابقة.

## 7) تشغيل الاختبارات

```
.\run_tests.bat dedicated
```

(اختبارات المرحلة الحالية فقط — سريعة)

```
.\run_tests.bat
```

(الاختبارات الكاملة — قد تستغرق دقائق)

## 8) إذا ظهرت مشكلة

- لم يتم العثور على Python: أعد التثبيت مع تفعيل Add python.exe to PATH.
- النافذة أغلقت فجأة: شغّل الأمر من PowerShell بدلاً من النقر المزدوج وسترى
  سبب الخطأ كاملاً.
- مسار فيه مسافات: ضعه بين علامتي تنصيص مثل المثال في الخطوة 4.
- الفحص يبدو عالقاً: انتظر — الملفات الكبيرة تحتاج دقائق.

---

ملاحظات تقنية (للدعم فقط): أدوات `tools` مكتوبة بمكتبة Python المدمجة فقط ولا
تحتاج تثبيتاً. تقرير الفحص يحوي `binance_semantics = NOT_VERIFIED` — أي أن أسماء
الأعمدة ومعانيها ليست مثبتة، والفحص يصف الملف فقط دون تفسير سوقي. خطوة الإعداد
تُثبّت المشروع من `pyproject.toml` ثم تُطابق pandas على السلسلة 2.x المعتمَدة
(اختبارات المشروع اجتازت الاعتماد على pandas 2.x وليست 3.x).
