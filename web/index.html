شو يعني الفريم؟

1D — الخريطة

كل شمعة تمثل يوماً. نبحث عن اتجاه التسليم والهدف الكبير للسيولة، لا ندخل منه.

4H — السياق

هل الحركة الحالية تدعم اليومي أم تصحّح ضده؟ وأين مناطق الـPD Array الأهم؟

15m — التكتيك

أين السيولة داخل الجلسة؟ هل حصل sweep، displacement، FVG أو كسر هيكلي؟

1–5m — التنفيذ

ننتظر تأكيداً حديثاً قرب المنطقة. اختيارك هنا ليس «على كيفك» بل درجة دقة مقابل ضجيج.

ليش أحياناً ما في TP2 رقمي؟

TP1 هو أقرب مستوى سيولة حقيقي. TP2 لا يُثبت إلا إذا وجد هدف أبعد مدعوم بتأكيدات مستقلة. إذا لم يوجد، يظهر Runner / Trailing بدل اختراع «هدف ذهبي».

ماذا لا يفعل التطبيق؟

  • لا يحوّل PENDING إلى Limit Order قبل displacement وFVG والتأكيد.
  • لا يعدك بنسبة نجاح؛ الباك تست الافتراضي لا يساوي التنفيذ الحقيقي.
  • لا يحدد عدد صفقات يومي أو شهري. السوق والشروط هما اللذان يحددان.
